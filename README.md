# Balina – Hestelogbog v9.0.1

Rettelsesversion efter test af v9.0.0.

## Dækkenguide
- Balinas specialkalibrerede guldlogik er bevaret.
- Aktuelle forhold er redigerbare og påvirker beregningen: døgnfold/fold+boks, læ, huld (under/ideal/over), pelsmængde og kliptype.
- Standardperioden er frem til kl. 15 næste dag, men sluttidspunktet kan ændres frit.
- Den valgte periode bruges reelt i vejrberegningen, også varme senere på dagen.
- Kraftig regn vurderes også på maksimal regnintensitet pr. time.
- Summer Series diskvalificeres ved kraftig regn/skybrud og problematisk vind.
- Forklaringsfeltet viser de konkrete Balina-input og vejrfaktorer, der er vægtet.
- Regn i boksperioden kan vises i prognosen, men vægtes ikke som udendørs belastning.
- Eksisterende 1–5 sikkerhedsskala er bevaret.

## Klipning
- Individuelle klikbare kliptyper med navn og kort forklaring.
- Fast filsti til den samlede kliptype-guide (`illustrations/clip-guide.png`).
- Kliptype justerer Balinas guldlogik; den erstatter den ikke.

## Foderplan
- "Det får Balina" er ændret til "Foderplan".
- Ingen automatisk foderberegning eller fodervurdering.
- Manuel tilføj/ændr/slet af produkt, mængde/hvornår og note.
- Balinas aktuelle døgnfold-plan er migreret: Optimal 3/4 mål én gang dagligt og wrap morgen + eftermiddag i bunker på jorden, med note om usikkert faktisk indtag.

## Sundhed
- Markerede Balina Premium/ejerfunktioner.
- Kamera-knap til foto direkte fra telefonens kamera, hvor browseren understøtter det.
- Foto vises kun lokalt i denne version og gemmes ikke som historik endnu.

## Kalender & pleje
- Smed og sadelpudsning har nu forskellige farver.
- Påmindelser er fortsat badges/banner inde i appen, ikke push-notifikationer.

## Størrelser og konto
