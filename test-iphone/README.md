# Balina – isoleret iPhone-test

Denne mappe er reserveret til Balina v9.4.11 TEST. Den almindelige app i roden af repository er ikke ændret.

Når testfilen `index.html` er uploadet her, bliver testversionen tilgængelig via GitHub Pages, hvis Pages udgiver fra main/root.

Testversionen bruger separat browserlager (`balinaHQ_iPhoneTEST_9411`) og deler ikke lokalt gemte data med den almindelige Balina-app.

**Vigtigt:** Dette er en teknisk test og ikke en veterinærfagligt godkendt dækkenanbefaling.
